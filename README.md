# משפחה במשימה 🏰

אפליקציה לניהול הילדים, בעיצוב של משחק: חוגים, רופאים, תורים רפואיים ותרופות.
היא בנויה קודם כל לטלפון. פותחים את הקישור בנייד ומוסיפים למסך הבית, והיא נפתחת במסך מלא כמו אפליקציה רגילה.

## מה יש בה

- **חשבונות למשפחות:** נכנסים עם Google או עם אימייל וסיסמה. כל משפחה פותחת חשבון משלה, והנתונים שלה גלויים רק לה.
- **אמא ואבא באותה משפחה:** מי שפתח את המשפחה שולח לבן או בת הזוג קוד הזמנה (או קישור שכבר כולל את הקוד). מאותו רגע שניהם רואים את אותם נתונים, ומה שאחד מסמן מופיע אצל השני תוך שנייה.
- **שיתוף עם חברים:** כפתור ״שיתוף האפליקציה״ שולח לחברים קישור, והם פותחים משפחה משלהם.
- **ילדים:** שם, דמות, צבע ותאריך לידה.
- **חוגים:** ימים בשבוע, שעה, מקום ומי מסיע. יש תצוגה שבועית וסינון לפי ילד.
- **רופאים:** שם, תחום, כפתור חיוג וכפתור ניווט בווייז.
- **תורים:** ספירה לאחור, מי לוקח, הוספה ליומן של הטלפון עם תזכורת, וסיכום ביקור.
- **תרופות:**
  - **בשעות קבועות:** כמה בכל פעם, באילו שעות, ומאיזה תאריך עד איזה. נרשם מתי ניתן ומי נתן, ומנה שלא ניתנה מסומנת ״באיחור״.
  - **לפי הצורך** (למשל אקמול): האפליקציה מראה מתי ניתן לאחרונה ומתי מותר שוב, ומזהירה אם נותנים מוקדם מדי.
  - **יומן נתינות** מלא.
- **המשחק:** ההורים מקבלים נקודות ועולים ברמות, ויש טבלת ״אמא נגד אבא״. הילדים מקבלים כוכבים, ויש קונפטי.
- עובדת גם בלי אינטרנט. השינויים נשלחים כשהחיבור חוזר.

## הפעלה בפעם הראשונה

צריך לעשות שני דברים, פעם אחת בלבד.

### 1. Firebase (החשבונות והנתונים), בערך 5 דקות

Firebase הוא שירות של Google, וחינמי בהיקף של משפחות.

1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com) ולוחצים **Create a project**. נותנים שם (למשל `family-app`). את Google Analytics אפשר לכבות.
2. **Authentication**:
   1. בתפריט: **Build → Authentication → Get started**.
   2. בלשונית **Sign-in method** מפעילים את **Email/Password**.
   3. מפעילים גם את **Google** ובוחרים אימייל לתמיכה.
3. **Firestore**:
   1. בתפריט: **Build → Firestore Database → Create database**.
   2. בוחרים מיקום באירופה (למשל `eur3`) ואת **production mode**.
4. **כללי האבטחה**: בלשונית **Rules** של Firestore מוחקים את מה שיש, מדביקים את כל התוכן של הקובץ `firestore.rules` ולוחצים **Publish**.
5. **הגדרות האפליקציה**:
   1. בגלגל השיניים: **Project settings → General**.
   2. למטה, ב-**Your apps**, לוחצים על סמל ה-Web `</>`, נותנים שם ולוחצים **Register app**.
   3. מעתיקים את הקטע `firebaseConfig` ומדביקים אותו בקובץ `firebase-config.js`, במקום `null`.
6. **אישור הכתובת**: ב-**Authentication → Settings → Authorized domains** לוחצים **Add domain** ומוסיפים את הכתובת של האתר, למשל `fox8682.github.io`.

הערכים ב-`firebaseConfig` אינם סודיים. Firebase בנוי כך שהם יושבים בדפדפן, ומה ששומר על הנתונים הם כללי האבטחה.

### 2. GitHub Pages (הכתובת באינטרנט)

1. במאגר ב-GitHub: **Settings → Pages**.
2. ב-**Source** בוחרים **Deploy from a branch**, ואז את הענף `main` והתיקייה `/ (root)`, ולוחצים **Save**.
3. אחרי דקה-שתיים האפליקציה זמינה בכתובת `https://<שם-המשתמש>.github.io/<שם-המאגר>/`.

## בלי Firebase

כל עוד `firebaseConfig` הוא `null`, האפליקציה עובדת ב״מצב מקומי״: בלי חשבונות, והנתונים נשמרים רק בטלפון. אפשר להעביר אותם לחשבון בענן עם ״הורדת גיבוי״ ואחר כך ״טעינת גיבוי״.

## קבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | שלד הדף |
| `styles.css` | העיצוב |
| `app.js` | המסכים והלוגיקה |
| `cloud.js` | החיבור ל-Firebase: חשבונות, משפחות, סנכרון |
| `firebase-config.js` | ההגדרות של פרויקט ה-Firebase שלכם |
| `firestore.rules` | כללי האבטחה. מדביקים אותם ב-Firebase Console |
| `sw.js`, `manifest.json`, `icons/` | התקנה כאפליקציה ועבודה בלי אינטרנט |

## בדיקה במחשב

```
python3 -m http.server 8000
```

פותחים את http://localhost:8000.

לבדיקה עם חשבונות בלי פרויקט אמיתי מריצים קודם את האמולטור, ואז פותחים את http://localhost:8000/?emulator:

```
npx firebase-tools emulators:start --only auth,firestore --project demo-family
```
